**Front-end**
Semantic HTML5, CSS3 (flexbox, grid, custom properties, keyframe animation), JavaScript ES6+ (modules, classes, async), responsive and mobile-first layouts.

**Accessibility**
ARIA-driven components: modals, tabbed overlays, expandable menus. Keyboard navigation, focus management, and `prefers-reduced-motion` support so animation never gets in the way.

**Internationalisation**
Multi-language and multi-currency interfaces built on the native `Intl` API (`NumberFormat`, `DisplayNames`, `DateTimeFormat`), including right-to-left layout support and locale-aware formatting.

**State and persistence**
Client-side state with `localStorage`, publish/subscribe stores, and live-updating UI without a framework.

**Browser APIs**
`IntersectionObserver` for scroll-driven behaviour, `matchMedia` for theme and motion preferences, touch and pointer events for swipe interaction.
